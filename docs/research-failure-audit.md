### 最近20题四臂的配对证据

- GAP7 vs MATCH7：纠错1、误伤1、净0；来源组 bootstrap 描述性95%区间 [-15, +15] 百分点。
- GAP7 vs NATIVE6：纠错2、误伤1、净+1；区间 [-10, +20] 百分点。
- GAP7 vs IMAGE12：纠错1、误伤3、净-2；区间 [-30, +10] 百分点。
- GAP7/MATCH7 对20题产生不同打包输入，但18题最终答案相同；20题中8题四臂全错、6题四臂全对；后验总变差中位数约0.0534。
- 这能支持“输入扰动发生而净纠错有限”，**不能**证明模型忽略视觉帧、看到了全部关键证据或某类时序融合必然失败。
- 工程验证显示80次问答均进入唯一开始/终态、无重复前向、0技术失败；该结论仅限快照所记实验，不能当作新阶段本地当前运行状态。

## 3. 证据等级与缺口

| 科学命题 | 现有证据级别 | 缺口与取证方式 |
|---|---|---|
| 追加/更换观察会带来纠错与误伤 | 已有小样本配对现象 | 缺乏与真实独立来源、证据充分性关联的确认 |
| 当前模型是否遗漏必需视频证据 | 未验证 | 需参考支持区间/关键帧与原视频版本有效桥接 |
| 模型在“必需证据已提供”时是否无法融合 | 未验证 | 需要参考证据完整的预注册配对试验；帧覆盖≠像素事实充分 |
| 原生视频机制普遍劣于多图 | 不支持 | 仅当前Sparse12配置观察 |
| 新方法有可发表创新性 | 未成立（retain 0） | 需要文献新颖性和强对照复核 |
| 跨数据集、跨骨干、3训练种子可复现 | 未完成 | 只有进入确认阶段后才执行 |

**科学解释不能越级**：证据区间被采样 → 像素中存在可见线索 → 模型感知到线索 → 正确绑定/融合 → 输出正确，是不同命题。只测准确率和输入变化无法直接辨识所有中间环节。

## 5. 下一步可证伪的研究问题（不是创新宣告）

在固定**12个唯一源帧**和相同主模型问答条件下，假定一组经检查有效的参考必需证据区间已经各被源帧覆盖，将其余非参考区间的帧从均匀背景选择换成**问题相似度较高、但不在已标注必需区间内**的帧，是否系统性改变准确率与误伤率？

- 此处“已标注必需”只表示数据集标注协议下的必要集合；不保证参考区间外没有信息，也不保证采到的图像已被理解。
- 若差异可重复，科学输出是一个有边界的**输入组成敏感性现象**，还不是新算法。
- 若无稳定差异，停止该路线，不追加第四个相近启发式。
