配套：[一页贡献定义](../research-proposals/natural-video-clock-contribution-brief-2026-10-24.md)。

## 1. 需要分别回答的两个问题

Q1：在相同采样画面下，以PTS替代索引/平均fps构造的时间码，是否改变已有自然事件区间定位结果？
Q2：使用已有均匀时间重采样，能否以可接受的计算与画面代价达到同样用途？

Q1的配对干预只隔离时间码输入，不能定位神经机制，也不能单凭答案变化证明变好。Q2允许实际帧变化，只衡量完整预处理方案，不将其差异归因为纯时间码。前置文字/时长对照用于显示先验答题能力。

## 2. 素材准入与固定分母

拟规模为8个不同原始录制，每源2道**已有**事件区间问题，16题×B0/P/N/T=64逻辑格。它是有意富集时间偏移的可行性试点，不估计自然发生率，不合并为64个独立样本。

在读取模型输出之前，一次登记至多16个候选录制。每项必须有确切文件引用、当前使用范围/版本依据、nongold问题ID与文本、独立原始录制关系、原媒体时钟与已有标注时钟之间的可核映射。默认只拟使用明确提供的本地新来源；本设计不授权媒体或标注下载、扫描旧目录、手工新标注或旧预测读取。

候选须满足：
- 原始自然录像，计划时长180–900秒；不人为改速或重封装制造VFR。不同裁剪/转码不能算独立源。
- 有可靠的帧显示PTS及持续时间；显示顺序、时间基、编辑列表/起点语义明确。不能用packet DTS代替帧PTS，不能因B帧而按packet到达顺序配帧。
- 既有事件区间与当前媒体同版或有确定映射。仅“单位都是秒”不构成桥接；不得估计偏移或根据模型答案调整gold。
- 问题文本与评分区间分开。每源选nongold ID字典序最前两题，不按答案、区间位置、事件是否被采到或历史成绩挑题。保留所有最终题；稀疏采样漏事件也是试点结果。
- 先按原始来源ID去重，再按SHA256(seed19与公开匿名源ID的规范串)排序，按下述两层各取前6/2，不依据漂移大小排名找极端赢家。不能在得到模型输出后补源补题。

对默认48个索引采样点，令
d_i = max_j |i_j / average_fps − p_j|，
其中p_j为经同一媒体原点映射后的帧PTS；所有量先按统一原点对齐，原点不能为凑相等而拟合。
高偏移层须为真实非均匀显示时间且d_i≥0.25秒，拟6源；
CFR参照层须全帧时序经时间基精度核验、间隔近似恒定且d_i≤0.02秒，拟2源。
这些是本试点事前操作阈值，不是行业标准。低d_i不能单独认证CFR。未达到8源/16题，登记缺项并结束该候选的当前准入，不造替代视频、缩分母或改阈值凑数。

原始媒体引用、标注/clock映射、实际解码接口仍待确定。因此本节不是已通过的数据资格，也没有授权本轮读取候选文件内容。

## 3. 四配置与可归因范围

| 配置 | 画面与时码 | 用途 |
|---|---|---|
| B0 | 同一原视频按索引均匀取48帧；原生processor用源indices/average_fps构造时间码 | 默认参考，不故意漏metadata |
| P | 与B0相同的48个RGB/顺序；每个temporal patch的首尾PTS平均，沿原生格式生成时码 | 已知精确PTS原则的诊断参照；需要公开透明的processor适配 |
| N | 在媒体显示区间按均匀时刻取48帧，选择该时刻实际显示的源帧，并用对应均匀时刻构造native输入 | 现有时间采样/规范化基线；允许重复帧，计入画面和CPU代价 |
| T | 与前三项相同的问题、时长和输出要求，无视觉 | 文字/时长先验参照 |

N优先使用CPU内存中的均匀时间采样，不默认需要ffmpeg转码或安装。若另选实际CFR转码，必须在正式合同前固定编码器、fps、映射/舍入与完整成本，不能与本N混称同一处理。

B0的索引为round(linspace(0,F−1,48))，具体舍入与库版本须在合同封存；F≥48。P的patch时刻为(p_2k+p_(2k+1))/2。T是末帧显示结束时刻减去已登记统一原点。N的目标时刻为u_j=j*T/48，j=0..47，使用覆盖u_j的左闭右开帧显示区间；按源time_base有理数比较边界。重叠覆盖、间隙、重复/缺PTS或未定义的覆盖记UNKNOWN，不擅自补时刻。N的构造时钟为48/T，indices0..47；它是该48帧均匀时间表示的时钟，不能冒充原始帧率。

所有视觉帧保持原始纵横比，经固定bilinear letterbox到192×288，边缘补0；无插值造中间内容、额外文字或可见时间叠字。不用音频、字幕或额外视觉模型。B0/P应有相同BF16视觉tensor、grid[24,12,18]、1296视觉tokens；N同grid与token数，但**不要求相同RGB或视觉tensor**。相同token数不控制全部计算差异。

共同prompt固定为：系统“You are a helpful assistant.”；用户“Locate the event described below in the video. Video duration: {T} seconds. Event: {existing_query} Return only a JSON object with start and end in seconds on the video's presentation timeline: {\"start\": number, \"end\": number}.” T用同一媒体时间轴/同一十进制表示，四配置完全相同；不加入源身份、原动作日志、区间位置、答案或前一槽回复。具体文字须在正式前封存，不能看结果后改。

## 4. P路径与强基线的诚实定义

现有本地目标是Transformers4.57.6/Qwen3-VL-4B。公开processor的_calculate_timestamps以indices/fps推导时刻，没有已验证的直接PTS参数。不能把给metadata添加字段、内部存在timestamps变量或decoder返回PTS当作P已接通。

拟P为隔离的新公开适配层：在已核API的时间计算入口，用当前请求的源索引→PTS只读映射返回patch时刻，保留原生时间码格式、tokenizer、视觉分支和其余流程。需要一次新的明确实现/媒体授权；不得静默改已安装库、伪造整数frames_indices、修改最终input_ids或把该科学干预称为普通兼容修复。P是诊断基准，**不是我们的新算法或已安装的开箱强产品**。

N是完整计费的已有方法参照。若发现可直接实现同一用途的现有PTS适配，应在冻结前把它列为强现有控制，记录版本与接口，并替代自实现P的角色。没有可验证接口就先结束输入准入，模型load/forward/generate/GPU均0，不用手工token注入绕过。

## 5. 真实CPU输入门与封存

只有后续正式合同明确授权的CPU过程才可检查媒体/processor；本轮不运行这些步骤。

拟一次构建并封存：
1. source/许可/独立性/clock桥接与nongold队列；原始评分区间保持隔离。
2. 帧索引、每帧PTS/显示时长、N目标时刻与帧归属；相同解码结果可在**本轮新根**共享并按一次实际工作计费，不能每臂假计一次解码。
3. B0/P/N的实际native timecodes、input_ids/attention、BF16视觉/网格与完整kwargs摘要，T无视觉。核B0/P只有预期时码文本差异，不能只核传入metadata。
4. 原生一位小数格式造成的量化误差单列：比较未舍入时刻及实际渲染时码，不能把0.05秒左右量化当作额外VFR故障。若B0/P最终输入相同，视为同一等价类。
5. 源码、runtime/processor/generation/prompt、队列和等价类封存。全部输入门未过，GPU0；不更改科学条件挽救输入门。

64个逻辑格按问题与配置完整保留；全输入、模型/生成声明及上下文完全相同者，只执行一次物理生成并映射回各逻辑格。不得把相同输入的两次采样当独立复现。四配置按源/题轮转执行，不把先前答案放入后续上下文。

## 6. 评分、主指标与失败解释

模型进程全部退出后，独立CPU scorer才可读指定的已有区间标签。标签端点按已登记时钟映射换算，不用B0/P自身validator作真值。严格解析一个JSON对象，恰start/end两个有限数值，0≤start<end≤T；不提取解释中的有利数字，不裁剪或交换端点。INVALID/FAILED/TIMEOUT/NOT_RUN保留在各配置16题分母，IoU主分按0计，同时分别公开状态；gold/映射不可用记SCORING_UNKNOWN，不偷填0或缩分母。

- 主量：每题IoU，先每源两题平均，再在预设6个高偏移源等权比较P−B0、N−B0；2个CFR源单独报告。全8源/16题表同时保留。
- 辅量：R@0.5、纠正/误伤/均正确/均错误配对表、T对照结果；合法输出的端点误差只能连同覆盖率作补充，不掩盖无效答案。
- 输入/成本：实际时码误差、N不同源帧数/重复帧与取帧位移、实际processor/生成次数、解码与预处理CPU wall、GPU完整包络、峰值内存、临时字节。共享准备只记一次，适配与重采样成本都实付；CPU标记或backend miss不换算成GPU收益。
- 本试点按录制配对描述，不报“小样本已证明泛化”的显著性；不同裁剪/题/配置/patch均不算额外独立录制。

## 7. 事前继续/停止判据

- 输入不齐、标注桥接未知、真实PTS不可靠、P接口/输入门失败：停止当前候选准入，不做GPU，不下达补路径/造VFR微包。
- B0/P在高偏移层未形成不同有效输入：无法检验Q1，停止，不把无效干预写成模型不敏感。
