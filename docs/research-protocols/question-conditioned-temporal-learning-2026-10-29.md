## 1. 要检验的主张

先只研究两个明确、不同、互不重叠事件的before/after判断。053的块交互路由、054的固定组合排序继续关闭；旧24题、旧预测、正确性及HourVideo开发答案不进入本轮训练、选择或评分。

首轮刻意使用同一种标准时间适配器架构，改变监督，避免同时改变架构和损失而无法归因。它是**冻结Qwen特征上的二元VQA小头**：输出直接来自当前视频和问题，不从旧答案池选择，不取用配对视频或另一个问题的预测。尚不向Qwen解码器注入新token，也不声称改善了冻结LLM内部推理或自由生成。

## 2. 四格单位与解释边界

对两个事件A、B，构建视频v0=A→B、v1=B→A；问题q0询问A是否先于B，q1询问B是否先于A。四格标签为：

| 输入 | q0 | q1 |
|---|---|---|
| v0 | 是 | 否 |
| v1 | 否 | 是 |

这只是定义示例。实际文件名、original/reversed标记、配对索引、源ID、标准答案、剪接点及事件标注时间**不进入小头或基础模型输入**。训练采样器可以使用训练四格关系；推理接口一次只接受一条视频特征序列和当前问题特征。不得读取另一格后翻转答案、强制互补或按组修复预测。

**四格全对本身不是新贡献，也不足以证明问题相关的时间定位。** 在只有两个事件的交换任务上，通用顺序判别加文字方向规则也可能得高分。首轮只决定联合监督是否有额外答题价值；若保留，后续仍须用同视频不同事件对、仅改变无关事件等控制检验更强归因。本轮不虚构这些控制的数据或标签。

## 4. 数据、划分与封存

### DyBench开发数据

仅event_sequence，不引入moving_direction/reversible_dynamics、Charades、旧HourVideo或新人工标签。按发布revision固定元数据、两段交换对应关系和媒体清单。解析原题的两个事件，固定生成英文问题：`Does the event "{A}" happen before the event "{B}"? Answer Yes or No.` 及交换A/B版本；所有方法共享相同实际问题文本。

事件相同、缺配对、无法唯一解析、原答案/交换关系不一致或无法确认两段非重叠构造的项，必须在任何模型运行前按固定规则排除并统计；不能见到模型失败后清洗。发布标签只供建立训练目标和评测，不提供事件时间/边界作为模型输入。媒体缺失或解码失败发生在封存后时保留计划分母。

以原录制来源分组，至少合并original/交换版本、同原视频不同问题/切片及已知多机位/同参与者录制关联；保留私有映射和依据。先由来源元数据分组，再按`SHA256("VLM055/" + source_group)`排序，哈希首8个十六进制转整数mod10：0..5训练、6验证、7..9开发测试。每split按该序纳入整个组，若加入将超上限则跳过整组并记录；不拆组凑数、不按答案或模型分数选组。

上限训练96、验证16、开发测试48个四格实例，总计160；最低分别64、8、32个，开发测试至少8个来源组。原录制身份不明的项不用于主开发划分。哈希划分不满足最低量时为DATA_INSUFFICIENT，不能事后换seed/调比例凑门。以上是开发止损规模，不是统计功效保证。

## 5. 冻结特征与统一小头

只用现有本地Qwen3-VL-4B-Instruct、现有环境。视觉及语言模型全部`eval`、`requires_grad=False`、`no_grad`；不更新其权重，不调用SigLIP/新模型/付费API。

每个视频在完整已发布片段上取12个等时间bin中点的RGB帧，224×224，以同一数组供基础Qwen和特征抽取。时序不足12个可解码时点、解码失败等保持失败状态，不能复制单帧补成成功。准确processor格式、tubelet映射及token排列须对照本机4.57.6实现确认，不凭tensor总元素数猜reshape。

视觉特征V取该版本Qwen主视觉输出、进入语言解码器之前的表示：按实际grid/tubelet次序保留时间轴，只对每个时间单元空间平均。12输入帧通常产生6个时间单元，**以已核实现为准**；不把空间token当帧。问题特征q取同模型纯文本forward中问题最后有效token的最终隐状态，保留词序语义，不平均成会使交换问题等同的词袋。接口、维数、预处理和padding行为在正式抽取前固定。

所有方法共享相同的V、q；不在训练中重算特征，不借标签截取事件。若文本超过冻结token上限128或processor不支持本配置，须在输入封存前判定不适格；不能在得分后换模板。真实抽取的首次forward就是正式预算内输入，结果复用，不设免费GPU探针。

小头固定r=64，所有有训练的臂**代码/参数/初始化完全一致**：

1. V逐时间单元线性投影到r，加固定正弦位置编码，经过无仿射LayerNorm及一层有bias的Conv1d(r,r,kernel=3,padding=1)残差/GELU，得h_t。
2. q经有bias线性投影/GELU得g；alpha_t=softmax(h_t·g/sqrt(r))。
3. u=sum(alpha_t h_t)，o=sum(alpha_t xi_t h_t)，xi_t为[-1,1]均匀位置。
4. x=concat(u,o,g,u*g)，有bias MLP(4r→r→1)，中间GELU，输出是/否logit z。

无dropout、额外可训练位置编码或虚假补齐参数。参数数应为r(Dv+Dq)+7r²+5r+1；若Dv=Dq=2560则为356673，但真实维数要报告，不以配置推测当实测。要求总可训练参数≤1M，且每臂所有参数实际参与计算/有梯度；主模型梯度始终None。

本架构是标准时间卷积、问题注意力与小MLP的具体组合，不宣称新架构。输入时间位置是正常序列信息，不能编码original/交换类别；该类别不是模型条件。

## 6. 五个方法与不冗余的监督

| 臂 | 训练 | 目的 |
|---|---|---|
| B0 | 无；原冻结Qwen对当前视频/问题直接Yes/No回答 | 基础能力锚点；不是同参数对照 |
| A | 上述普通时间适配器，四格逐项BCE | 主强对照；也看到全部四格，不能让I仅靠多见数据获益 |
| V | 同A，BCE + 0.25 L_video | 固定问题、仅视频配对关系监督；不是完整CRPO复现 |
| S | 同A，BCE + 0.25 L_joint，联合项的分组打乱 | 检查普通margin/均衡正则化是否已经解释收益 |
| I | 同A，BCE + 0.25 L_joint，真实视频×问题四格 | 本轮候选，仅检验真实分组的联合监督增量 |

按实际发布标签令s=2y00-1，yij在视频/问题任一维交换后翻转。每格logit zij；mij=(2yij-1)zij。

```text
L_BCE = mean_ij softplus(-mij)
c = s*(z00-z01-z10+z11)/4 = mean_ij mij
L_joint = softplus(1-c) + mean_ij (mij-c)^2
L_video = mean_j softplus(1 - (2y0j-1)*(z0j-z1j)/2)
```

普通四格CE求和本身等于逐项监督，不能换名叫新联合损失。这里联合项额外约束四格平均有向响应及同组margin离散度，是否有效完全交给A/V/S对照；这些运算也是已知margin/一致性工具，不凭公式声称原创。

S保持BCE原四格不变；只为联合项把同一batch的8个真实组按训练标签重排为正/负/负/正后，格0来自组k、格1来自(k+1)mod8、格2来自(k+2)mod8、格3来自(k+3)mod8。8个伪组用到每个logit恰一次；无改标签、无新增forward。I的L_joint使用真实组，batch固定8组。不得让S损坏单格标签而制造弱对照。

A/V/S/I使用同两个seed=19、73；每seed共享初始state_dict及同一预生成训练组序列。AdamW，lr=1e-3、weight_decay=0.01、betas=(0.9,0.999)、eps=1e-8、梯度clip_norm=1、float32、batch8四格、有放回均匀抽组、每配置250次更新。4臂×2seed=8次训练，共≤2000次optimizer.step。只保存/评估最后一步，不扫lr、loss权重、步数或检查点。样本曝光数、参数量、更新数相同；不虚称附加损失的实际CPU开销完全相同，逐臂计量。

## 7. 单格推理、评分与投入门

B0使用统一问题模板/官方外部问题，贪心max_new_tokens=8，仅允许确定的Yes/No解析（去首尾空白，完整Yes/No及可选末尾句点）；其他输出INVALID，不反思/重问。小头z>0输出是，否则否，精确z=0固定否。每条独立推理后封存，禁止按四格强制互补。

主单位是四格实例，不是4条独立样本。对每seed报告I−A、I−V、I−S及I−B0的全对率差、仅I对/仅对照对/双对/双错、按来源组分层的差异。跨seed不累加样本数。按来源组有放回配对bootstrap，10000次、固定seed55029，给95%区间；来源组不明或不足时不冒充有效独立推断。区间只作不确定性报告，下面是开发投入门，不是显著性认证。
