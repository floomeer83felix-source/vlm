## 调查对象

优先：TRACE / VES-Bench、HERBench；备选：CaST-Bench。对每个资源：
1. **来源与版本**：官方论文/主页/仓库/HF 数据页、公开 commit/revision、split、元数据文件路径及可见修改时间（若有）；未知写“未确认”。
2. **许可及访问条件**：标注、视频和问题是否允许本地研究，是否有非商业/申请/限制；链接到原始许可证或网页依据，不能以“公开网页可访问”代替授权。
3. **结构与语义**：公开元数据里字段是否存在：题目、视频/来源ID、参考证据时间区间或关键帧、是否有联合必需的规范、帧坐标/时间单位、是否可判断三个非重叠区间与 <=12 个锚帧；分清论文描述、实际字段检查与猜测。
4. **时间桥接**：标注是秒数/帧ID/时间戳哪一类，视频 FPS/VFR/PTS 有何版本配套，是否能证明同版本媒体到标注的对齐；**只靠文字定义不能宣布实际桥接已通过**。
5. **身份与规模**：报告题目数、视频数、操作性来源组数各自依据；能否实施与历史源/封存集隔离。没有可核对文件时不能保证“≥40独立来源可用”。
6. **零模型成本与下载边界**：记录总元数据网络读取大致量及访问失败；不获取完整数据集、ZIP成员、原始媒体，不启动模型或GPU。
