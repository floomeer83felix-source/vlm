## D：先定义答案的变换规律

设唯一、可追踪事件实例A在10秒、B在25秒，总时长40秒；下面全为虚构例子。

| 抽象问题/变换 | 数学与语义结果 |
|---|---|
| “A与B相隔多久？”；完整反转t'=40−t | 原绝对间隔15秒，反转仍15秒。相同回答可正确，不能据此诊断时间失明 |
| “B在A后多久发生？”；同一反转 | 原给定A先B，反转后B先A；原after前提失效。不能无条件改成另一个正间隔选项 |
| “A是否先于B？”；完整反转 | 唯一实例且不同时发生，真变假。须保证逆放仍指同一可识别事件，选项确有合法映射 |
| 交换问题中A/B，不改视频 | 绝对间隔不变；有符号tB−tA变号；先后判断翻转；after问法可能失效，依题型分别定义 |
| 所有时间戳平移+c | 间隔和顺序均不变；不能认证标注与媒体实例同钟 |
| 单调正比例时间缩放 | 顺序保持，数值间隔乘比例；多选答案字母是否变取决于单位、分箱及选项 |

仅倒置帧列表、却留原时间戳/位置标签，制造的是冲突输入，不等价于一致的时间反转。
重复事件、持续事件端点、裁剪丢失实例、不可逆动作的语义破坏，均可能令自动标签变换无定义。
必须先固定实例、时间坐标、问题类型和选项映射；未知则不得自动翻gold或补人工标签。
[025/030冻结问题](../../research-protocols/development-temporal-diagnostic-2026-10-20.md)
已经给出A先B，所问是未知间隔；不能直接测“从视频发现未知先后关系”。
[Before It Fades §3.2](https://arxiv.org/html/2610.01595v1)也区分时间敏感与空间/无关控制题；
其反转方法不能替代本题型的标签语义证明。
