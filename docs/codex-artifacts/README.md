## 允许的材料

- 脱敏的 Markdown 研究审计、输入/输出契约说明、只含聚合统计的 JSON/CSV、小型无秘密的可复现命令说明。
- 工作区代码与配置的**结构摘要**、相对路径、版本号及文件哈希；不直接上传未经检查的源码或完整配置。
- 对实验报告的独立审计记录；准确率等必须注明来源、样本量、分母、配对纠错/误伤、成本及限制。

## 严禁放入公开目录

模型检查点/权重、原始或受限视频/帧、数据集原文、私有问题及标准答案、逐题评分标签、完整运行账本、个人用户名/绝对路径、API Token、SSH 密钥、环境变量、隐私或商业秘密、可据此重识别保护身份的ID/哈希列表、含敏感命令行的原始系统日志；也不要上传压缩包、未经审查的自动生成大文件。

## 上传纪律

1. Codex 只能写当前 READY 任务自己的附件子目录，以及 `docs/codex-results.md`，不要更改其它研究文档、历史回报或 PR #1。
2. 先确认当前分支与工作区状态，不删除/覆盖其他人的改动；避免把本地实验目录与公开 GitHub 文档目录混为一谈。
3. 提交前执行 `git status --short` 和 `git diff --cached --name-only`，人工检查即将公开的内容是否包含敏感信息；只 stage 允许的文件。
4. 仅上传文本附件和结果回报，尽量不超过每文件 20 KiB；超过则只上传总结与可安全披露的哈希/索引。
5. 需要改写历史或添加大型/敏感材料，先请用户确认，不擅自扩大权限；发生冲突不强推 Git 历史。
6. 一项 READY 任务交付后即停止，等 ChatGPT 审查与新任务放行；不默认自主连续运行。
