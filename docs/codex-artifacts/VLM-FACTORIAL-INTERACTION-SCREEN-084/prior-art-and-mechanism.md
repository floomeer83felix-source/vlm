## Exact object being screened

For a deterministic scalar pre-threshold logit function, define

\[
I_f(V,q)=f(V,q)-f(V,\tau q)-f(RV,q)+f(RV,\tau q).
\]

Here R reverses the external index order of existing frozen units, leaving their contents intact; tau swaps the two roles using only the current question. Neither transformation may consult an answer, source identity, paired prediction or original/reversed flag. A deployed text parser and tau encoding have not been implemented or qualified by the synthetic code. Ambiguous, overlapping or repeated-event questions would require a separately frozen validity policy.

Let T act on functions by `(Tf)(V,q)=f(V,tau q)` and U by `(Uf)(V,q)=f(RV,q)`. They commute and square to the identity. Thus `I=(1-U)(1-T)f`, and the normalized operator `P=I/4` satisfies `P²=P`. This is the conventional odd/odd factorial contrast. Substitution gives `I(V,tau q)=-I(V,q)`, `I(RV,q)=-I(V,q)` and `I(RV,tau q)=I(V,q)` for **any** deterministic f. No event correctness assumption enters this proof. Antisymmetry observed after applying this operator is therefore imposed by construction, not independent evidence of learned temporal reasoning.

For `f=a(V)+b(q)+c`, the two within-video question differences are both `b(q)-b(tau q)`, so I is zero even if V contains useful information. For `f=s(V)r(q)`, expand the contrast as `(s(V)-s(RV))(r(q)-r(tau q))`; when both factors are odd, it is `4s(V)r(q)`. These calculations establish representational possibility for a constructed scorer, not that a given frozen feature interface or optimizer can learn it. A zero contrast can mean a missing readout interaction and does not identify absent source information. Positive logit rescaling scales I, so its magnitude has no universal semantic threshold.

Reindexing contextual features does not recompute the visual encoder, remove embedded original positions, reverse pixel motion, or simulate physical reversal. Even a valid role swap need not imply a complementary answer outside the narrowly qualified two-distinct-event strict-order setting. No causal identification assumptions or semantic grounding evidence follow from a difference-in-differences expression alone.

## Specificity failure, deployment and cost

The synthetic counterexample uses **ordered static badges multiplied by lexical role sign**, entirely ignoring event identities. It satisfies both sign changes and has the same absolute I on a correlated and a semantics-decoupled example. It gets4/4 synthetic answers in the correlated orbit and0/4 in the decoupled orbit. Thus identity-correlated ordered nuisance can survive the contrast. A truly reversal-invariant global static function cancels; the counterexample does not incorrectly claim otherwise. These are countermodels to specificity, not new negative results on real video.

Each current `(V,q)` contrast requires **four scalar head-logit evaluations** and representations for q and tau(q); an uncached tau requires an additional text encoding. Reversal indexing, validity checking and cache lookup also have cost. Sharing parameters does not make these four calls one call. 062D's one-head cached evaluation and cold end-to-end deployment are different cost scopes. No cross-example score lookup, voting or paired-answer flipping is part of the proposed interface. Cache reuse would need complete input/state identity and persistent accounting under a future contract.

The computation can depend solely on the current video's stored units and the current question plus its deterministic role swap, but practical deployability also needs a qualified parser, valid transformations and an effective underlying scorer. None is established by 084. **No technical difference strong enough to justify a real experiment was established.** The subsequent gate document is a dormant qualification specification, not an instruction to execute it.
