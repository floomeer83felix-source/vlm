## 1. 观察、输出与风险先冻结

令观察O包含查询q、获准且实际提供的证据摘要Z、grounder区间I、候选置信与公开provenance描述D；本轮并未取得这些真实输入。潜在世界w还包含真实源版本v*、到统一评测坐标的映射m*、答案a*、证据区间E*及事件身份。映射集合M(O)必须由可核D或合法监督约束，不能凭未读字段捏造；没有依据时不是默认小Gaussian扰动。

输出Y=(A,a,J,v)或拒答：A∈{0,1}表示接受，J为证据集合/区间，v为所声称版本。联合错误L为“答案错、版本/坐标归属错、证据判据不满足”三者的并集。证据判据必须事前指定：完整包含E*、固定tIoU阈值或正确事件身份是不同目标；本报告分别讨论，不能用宽区间包含率替换精确定位/身份成功。

选择性风险 `R_sel=P(L=1 | A=1)`，覆盖 `c=P(A=1)>0`；全拒答时该条件风险未定义，不是0风险成功。另报 `P(A=1,L=1)`、返回集合时长/凸包长度、定位质量及成本，防止返回整视频以获得平凡包含率。无合法联合标签及目标分布，c可从执行统计但R_sel不可认证；本轮连执行统计也没有。

## 2. 最强零创新基线，而非稻草人

| 操作 | 已能解释的收益 | 边界及公平比较 |
|---|---|---|
| B0：同版确定性正确换算 | m*已知时对I作正确timebase/offset/trim映射，修复坐标误配 | 工程修复不能当算法增益；所有方法先用同合同 |
| B1：映射集合像并集 | `J0=union_{m∈M}m(I)`；若m*∈M且源真值在I内，则目标真值包含于J0 | 不增加版本识别信息；若输出必须单区间，用凸包并分别报膨胀量 |
| B2：常规保守扩张 | m(t)=t+b、b∈[b-,b+]时J0=[s+b-,e+b+]；仿射/分段时求集合像 | 对offset两端取包络是普通鲁棒工程；M缺失或未包含真映射则无保证 |
| B3：COVER类后校准 | 固定grounder及嵌套返回集合，合法held-out标签用于边界/集合非符合度校准 | 只在同目标、校准/测试有效可交换等条件下引用覆盖；不能自动搬到错版/QA条件风险 |
| B4：置信、宽度预算及版本可识别性弃答 | 对同候选池按置信筛选，或对过宽/版本未识别输出拒绝 | 这些门本身已有先例；非零覆盖、同标签和同预算比较，阈值不在审计集挑 |
| B5：VideoMind式证据复查 | 固定候选/证据下grounder—verifier—answerer检查支持度 | 模型verifier不是媒体版本证明或独立GT；总复查成本必须计入 |

固定这些操作、次序、输入、参数与随机种子后，所谓H1若仅调用同操作组合，则强基线可逐步模拟同一输出；这种**限定组合的等价**足以否决该版本的新算子主张，不证明一切可能新方法等价。校准和映射并集未必可交换，比较应允许基线在独立开发资料上确定合理次序，不能故意只给弱次序。

即使包含率能由条件推出，联合选择性风险仍不随之成立。若子错误E_i有边际上界α_i，则 `P(L)≤Σα_i`，但 `P(L|A=1)≤Σα_i/c` 才是一般边际推得的界（再截至1）；要直接Σα_i条件界需各 `P(E_i|A=1)` 有效受控。例：校准后边际错误只集中在被接受的α比例样本，边际错误α而接受风险为1。宽度/置信筛选与错误相关时不能忽略此选择效应。这是纸面概率反例，不是本项目数据。

## 4. 两个纸面双世界反例

### A. 同观察，不同trim/offset

取抽象局部证据区间I=[u,u+ℓ]、ℓ>0。w0把局部文件关联到canonical起点b0，w1关联到b1，且|b1-b0|>ℓ；两世界观察O完全一样，但目标证据为E0=I+b0与E1=I+b1，互不相交。D只有库名/无裁剪见证，故两世界均允许。这里的符号不是真实UID、offset或样本。

若要求输出一个正确版本绑定的局部区间，且宽度上限小于两目标间的跨度，正确接受集合G0与G1不相交。任何仅依O的确定算法在两世界输出相同，所以不可能都正确接受。随机算法在两世界有同输出分布Q；因G0∩G1为空，有Q(G0)+Q(G1)≤1，至少一个世界正确接受概率≤1/2。这个界针对无条件正确接受概率，不是任意接受率下的选择性风险界。返回并集可实现两世界的粗包含，或全拒答安全停止，但均不能证唯一版本/紧定位；没有覆盖/宽度要求时不主张“一切集合覆盖皆不可能”。

### B. QA答案相同，证据实例或媒体版本不同

取两处外观/语义等价的重复事件。w0的q对应第一次实例，w1对应第二次（或相同局部素材绑定到另一源版本）；已提供观察中没有实例见证或版本锚，答案a*相同，而对应的唯一证据身份或精确区间不同。即便答案准确率100%，对证据归属仍落入上述G0∩G1为空的情形。重复观察相同摘要、增大记忆、对同O再加verifier或答案置信均不能创造区分世界的信息。

若评测允许“任意一次均可”的真值，G0和G1可能重叠，此反例不适用；必须事前定义query指向哪次、什么版本及证据成功标准。因此本反例是可识别性条件，不是宣称HourVideo真实存在这种样本，也不使用QA答案制造GT。

## 5. 一般不可能性与退出

定义同观察等价类W(O)。要对每个可行世界都正确接受，输出必须属于 `intersection_{w∈W(O)}G_w`；交集为空就只能拒绝或放宽输出语义。集合并集处理的是包含不确定性，不能替代这项身份可识别性。分布校准依赖有标签、受约束的目标分布，也不能凭空排除未见世界。所需额外信息至少能区分相关世界，例如受许可的同版转换见证及独立证据标签；其取得、可信度与信息量不是本轮已解决问题。

**结论**：H1普通“正确换算＋M像并集＋COVER＋置信/宽度弃答＋证据复查”可被上述组合实现，H1_NOVELTY_NO_GO。当前没有提出超出它的可验证算子、constructive non-equivalence witness或新保证。残余待保留创新问题数为0；识别所需信息的必要性可记为工程/统计前提，但不包装成算法。NO_GO_FOR_EXPERIMENT，等待科研审查。
