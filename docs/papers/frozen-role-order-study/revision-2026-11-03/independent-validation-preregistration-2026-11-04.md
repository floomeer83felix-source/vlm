**目的**：为论文中“角色差分D相对C的受限效果”寻找真正独立且任务定义可比的证据，而不是另起一个L/M/R连续补段任务后把不同问题的分数加在一起。**本文件没有真实新结果、没有新训练授权；不得把任何计划表、预计阈值或未运行单元写进论文结果表。**

## 1. 科学问题与可证伪主张

- **H1（有界复现）**：在此前未用于任何模型/结构/超参数/seed挑选的独立原视频和同等四格语义严格资格下，预先冻结的D（角色差分）相对C（普通标准化）在**同一实例上**具有更高四格全对率。
- **H2（角色特异性）**：若D确有角色相关收益，必须不只是强一般文本几何扰动N、文本-only、固定无关视频或来源/裁剪/外观捷径造成的提高。
- **H3（时间真实性）**：模型应相对于匹配的视觉静态/时间破坏对照表现出具体当前视频时序信息的增益。只需满足符号反转、互补一致性或输出改变，均不算H3成功。
- 任一H未被新实验支持，最多保留原论文“特定冻结接口上的相对关联”，不得升级为新算法、普遍时间理解或因果语义定位。

## 2. 第一关：数据合法性与真正的来源独立

优先检验**当前论文两事件问题的可迁移性**，不将085计划的自然L/M/R三段连续性作为现有C/D论文的必备任务；两者需要不同的ground truth构造。独立验证候选可以是公开新发布者、其他合法的两事件互补视频对，或经严格资格确认的TimeBlind真子集，但**目前没有确认可用的合格资产**。

要先冻结的数据资格表：
`source_license,original_recording_key,participant_key_if_known,clip_start/end,static_scene_key,train_dev_test_assignment,question_pair_validity,video_pair_temporal_only_difference,paired_labels_and_review_status,pretraining_overlap_unknown`。
只有脱敏的来源聚合计数可上传公开GitHub，不传个人/源标识/媒体/真值映射。

- 两视频必须能确认同一对事件语义、可读视频顺序差及互补的两条严格before问句；视频是否仅在时间因素不同需独立人工或来源标注证据。真实逆放、重拍和拼接不同，不混同。
- 所有训练/开发/新测试按**底层原录制/参与者/来源family**隔离；新集合不得与50Salads已用50实例、Breakfast训练/开发、同管线VIDHALLUC已审50项及其他已查看测试源重合。若不能证据化隔离，标签为`EXPLORATORY_USED_OR_UNKNOWN`，不宣称独立复现。
- 固定 eligibility/ineligibility 规则、source membership、样本量、阅读者复审程序与版本hash，**在任何新模型输出和测试答案查看之前**。不能从预测结果挑容易样本、用已看过的TimeBlind test调参，不能用作者发布的test直接当训练池。
- TimeBlind数据/媒体、Perception Test train、Ego4D当前私有资产的真实可用性/许可/源独立情况需要分别审核。旧085仅确认27根内文件的size，5根外UNKNOWN和32个自然L/M/R时钟未知；**这些均不是新独立C/D实验输入合格证明**。
- **DATA_GATE_FAIL**：没有合法可用媒体、配对四格标签资格不成立、来源交叉或样本量不足以进行预设检验。失败时只报告元数据判据，不训练、不扩大媒体访问。

## 3. 第二关：先验证普通模型正常可学

有了单独授权和真实训练集后，先在**仅训练样本**上复现原普通C头及正常序列头的有界拟合，固定数据/前向/参数数/更新数/初始化及优化器。H1在训练任务不成立时不能与模型未学会混为一谈。为便于事前客观停线，建议**注册拟合合格门**为：3个预先固定seed每个在final checkpoint达到训练四格全对率≥90%，且源码绑定核验通过；否则诊断数据/特征接口但不访问新test。此90%只是拟议资格阈值，**在首次新真实训练前由作者确定、签核，并不根据结果再调**。

如采用老C/D冻结头零训练直接迁移，则不需要新拟合，但须先锁定目标视频/问题映射是否与旧模型输入分布、tokenizer及前处理相容；**不能把不相容问句上模型失败当成对角色差分普适性的负结果**。冻结头验证与重新训练验证必须分开报告。

## 4. 第三关：强对照和成本公平

| 条件 | 目的 | 必须匹配/报告的成本 |
|---|---|---|
| C：普通训练集标准化视图 | 主对照；不能只比随机猜测 | 与D同模型、seed、初始化、train stream、250-step或事前预算 |
| D：交换两个事件角色差分视图 | 被检验候选；非公认原创算法 | 同读出参数；额外角色交换文本编码单独计费 |
| N：与D同形式但无关文本锚 | 控制差分归一化与几何扰动，而非只看两旧seed | 同六seed，anchor仅由train决定，不能看答案 |
| C+强时序读出基线 | 防止与欠拟合对照比较取得虚假优势 | 预注册容量、序列顺序保留、训练达到拟合门 |
| Text-only / 当前视频固定有序无关替代 | 检查语言/视频来源捷径 | 问句原样，固定替代视频由train确定，不可挑对模型有利的替代 |
| 时间破坏/内容固定排序 / 去运动静态 | 区分顺序信息、外观和时间戳捷径 | 必须同时验证转换改变什么、保留什么；不能当真实物理逆放 |
| 冻结完整Qwen基础模型 | 仅作为另一个系统层级参考 | 非同容量比较，使用实际相同视频/问题、冷启动成本分开记 |

训练条件对等需同一逻辑四格、同一真实参数量（不只是名义层数）、同seed独立初始化克隆/批次、相同更新及最终checkpoint规则；若方案多读了真实视频帧/多编码文本，分别报告训练暴露/模型forward/缓存与推理时延。**实验次数/seed不能按事后效果增加**。

## 5. 指标、统计和真正的过关条件

- 主指标：**每个独立视频对四格全部正确的二元比例**（与论文原任务一致）；次指标：4N单项准确率、问题交换不敏感率、原视频相对固定有序无关视频差、互补一致性、FLIP/HOLD及失败原因。四格算一个实例，不计四个独立样本。
- 成对C-D同一**source**层上的差，用预先决定的来源簇级paired bootstrap/置换检验，发布完整来源分母和区间；同source的四格、重排及六seed不是相互独立的源。存在多强对照时，预注册单一主比较及多重性策略。
- 成功至少同时要求：按事前功效分析确定的**独立来源数**足够、合格普通基线拟合成功、D对C的来源簇主比较效应区间下界大于0、D对N与强时序基线的预设非劣或优势要求满足、替换当前真实视频导致方向明确且达到事前最小实用差的下降；不能只凭seed 6/6正和相对百分点提升认作强证据。
- **数据与设计尚未定稿**：最小可检测差、独立源数、具体区间方法与停止阈值必须在首次未用测试分数前根据许可、功效和实际标签资格冻结。当前不填“预期准确率”，不把原050Salads的12.67pp作为独立实验的预注册效应或判断依据。若source family不能核实、有效独立数太少或未通过fit gate，则**HOLD/STOP**，不能补选seed、调loss、换数据篡改门。
- 要有**一次性密封测试**：train-only冻结模型和全部超参数/验证方案后，方可访问此前未用的真实测试预测/标签；同一盲测不反复挑选checkpoint/结果好坏。
