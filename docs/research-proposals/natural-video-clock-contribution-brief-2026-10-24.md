# 一页贡献定义：自然视频时间信息保真与修复代价

2026-10-24（北京时间）。**DESIGN_COMPLETE / ENTRY_UNRESOLVED / NOT_READY。**
配套：[最小真实对照方案](../research-protocols/natural-video-clock-feasibility-design-2026-10-24.md)。

**问题与使用者：**本地单卡Qwen3-VL用户对已有自然录像作事件区间定位时，平均fps构造的时间码是否影响结果？保留PTS与均匀时间重采样各付出什么代价？

| 要素 | 本候选的明确边界 |
|---|---|
| 已有覆盖 | Meta-Video已有评测配方研究，VeOmni已说明VFR限制，TorchCodec已有PTS/时间采样；这些认识和接口均不主张为新贡献。 |
| 拟争取的增量 | 绑定原媒体时钟、实际帧、原生时码与定位输出，测量真实任务影响，并给出强现有修复比较后仍有用途的效果/成本取舍。当前只是待证经验/工程贡献。 |
| 四项对照 | B0默认索引/fps；P同画面的精确PTS诊断适配；N已有均匀时间重采样；T同问题/时长的文字对照。P不是现成开箱产品，也不当作我们的新算法。 |
| 最小规模 | 拟8个独立录制、每源2道既有问题，64逻辑格；6高偏移源与2经认证CFR参照。相同实际输入合并调用，保留逻辑分母。 |
| 主证据 | P−B0观察同画面时码干预；N−B0衡量完整预处理取舍。按录制汇总IoU、无效/纠正/误伤，另报时码误差、重复帧、CPU/GPU和存储成本。 |
| 研究门槛 | 可靠素材与标注时钟桥接、实际输入干预、跨源一致性、已有方案之外的新经验或技术增量均须有证据；试点只决定是否继续确认研究。 |

**事前停止：**入口/桥接不成立、PTS适配未接通、有效输入未变、任务收益不足或只在单源出现，或者现成修复已解释全部用途而无新经验结论，就结束候选；不改提示、造VFR或补跑坏例。
