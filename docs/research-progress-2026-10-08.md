# 长视频主动视觉推理研究进展

更新日期：2026年10月8日（北京时间）  
目标：以《计算机学报》这类高水平期刊为研究目标。  
阶段状态：本次进展文档上传后暂停研究与自动续作，等待用户明确恢复指令。

## 1. 当前结论

**目前没有经实验与创新审查支持、可作为高水平期刊核心贡献的新机制。** 原始“关键帧检索 + Evidence Memory + 自适应补看”组合及后续具体候选均未达到预设投入门槛。已有工作形成了可复核的实验、成本记录和负结果，但不能据此声称研究成功或保证发表。

关闭的是已测试的具体操作及本轮有限候选阶段，不是证明所有主动视觉推理方法无效。整体期刊目标尚未完成；暂停期间不新增下载、模型调用、实验或候选审查。

## 2. 研究范围与资源

- 原问题：预算约束下，长视频问答应观察哪些帧，以及何时停止观察。
- 资源：RTX 3090、64GB内存；复用既有 conda `pytorch` 环境，不新建环境，不更改 Python、PyTorch、CUDA。
- 主模型：冻结的 Qwen3-VL-4B-Instruct；检索编码器 SigLIP。第二模型 InternVL3-2B 原计划用于跨模型验证，尚未形成完整跨模型有效性结果。
- 使用本地开源模型，无付费API、云GPU或新增人工证据标注。
- 第一阶段保留原始帧、时间戳与观察状态；文本 Evidence Memory 压缩尚未进入有效性验证。
- GPU串行、操作系统锁、持久调用账本与断点恢复；已开始的问答不得因中断重复前向。

## 4. 最近的四臂实验

### 4.1 假设与对照

在相同的12个已观察源帧上，按真实源时间跨度拆开一个原生双帧融合单元，检验能否改善回答。没有增加独立观察帧。

- **GAP7**：拆分源时间跨度最大的帧对。
- **MATCH7**：同容量、同clip数量的固定哈希位置对照，拆分其他帧对。
- **NATIVE6**：原始6个双帧融合单元。
- **IMAGE12**：12帧多图强基线。

拆分臂显式重复两个语义单帧，均有12个唯一源帧、14个提供槽和7个时间patch。四臂提供相同完整端点时间账本；原生空间预算按每clip长度计算，不加入无意义的成本补偿调用。普通原生与多图保留更便宜的完整处理器路径。

### 4.2 数据与技术验证

身份初筛得到680条项目训练候选记录、366个内容SHA。它们属于MLVU官方开发数据中的固定项目训练分区，不冒称上游官方训练集。

采用前瞻固定的32源工程获取宇宙，最终选择仅在该宇宙内按实际组件规则进行，不代表全366源的首24个样本。30源完成文件与指纹验证，2源因预设单文件上限失败且未替补；10605个指纹比较后留下20个操作性组件。

339份历史指纹摘要可用，450个保护身份的指纹覆盖缺失如实记录。内容哈希、组件与已知重复筛查不等于真实事件独立性证明。最终20源的实际名义时长约196.63—538.7秒，属于中短片探索性机制开发，不能作为独立长视频外部验证。

技术验证包括：

- 12项抽象编码检查。
- 6种合成输入的实际CPU处理器检查，12次video处理、6次full处理、78次RGB提供；耗时约43.49秒，不加载模型权重。
- 7项运行器与评分隔离检查。
- 首题四臂真实输入核验，以及首4次问答有效性核验后才执行其余76次。
- 全部80次唯一开始／终态记录及20组输入核验，无重复前向、无失败。
- 独立科学复核2547项，0差异；2000次配对操作性来源组bootstrap精确复现。

CPU检查仅证明技术合同，不证明语义grounding或新机制有效。

### 4.4 失败定位

一次已有记录诊断覆盖20题、120帧对、80个后验及183项输入绑定，无缺损；新增CPU/IO约0.142秒，未重新运行模型。

GAP／MATCH的20个输入均不同，18题最终答案相同。后验总变差距离中位数约0.0534，范围约0.000089—0.9365；说明数值响应可以变化，但没有净纠错收益。8题四臂全错、6题四臂全对，不能据此推断“忽略图像”“缺少证据”或语义grounding。

## 5. 参考事实测量前置检查

为区分未观测支持与模型利用问题，曾核查AGQA公开程序、参考节点和帧字段。官方说明支持program、sg_grounding及FrameID等字段，但参考图中的派生关系、动作边界、可见性、闭世界语义与同版本原视频帧桥接尚不足以形成“答案唯一性”证书。

因此测量目标收窄为：最多16帧在参考标注坐标上能够覆盖多少明确单帧支持节点。该指标只是离线注释覆盖上界，不是正确率、像素充分性或可部署策略。

实际访问过程均有独立预算和收据：

1. 首次限额探测返回HTML且没有有效Range，未取得记录。
2. 经当页明确的正常匿名下载表单，取得完整ZIP目录；3次HTTP、68022字节，不读取成员。
3. 固定311字节目录再次取得并持久化成员元数据；3次HTTP、2776字节，无成员内容读取。
4. 两个记录容器声明解压大小约2.56GB及1.28GB，超出8MiB微查预算。在读取内容前终止；记录数为0，U16未计算。

这只表示本次有界获取前置未完成，不表示整个AGQA不可用、登录被拒或数据没有相应字段。不再延长该访问或schema链。

## 6. 创新审查与当前处置

最新创新性工作按用户要求使用GPT-6.1-sol ultra；常规工程与重复核验使用medium／low。

有限决策卡比较了三个方向：同帧细节恢复、纠错／误伤选择性付费、本地第二阅读者。当前分别与zoom、learned-benefit和model-routing结构重合，没有保留候选。这里的判断不是完整文献穷举，也不是声称每种可能实现均已发表。

随后形式审查表明：没有额外假设时，同一当前可观测状态甚至相同追加观察仍可能对应纠错或误伤，不能保证逐题安全。新鲜配对测量、独立来源及分布假设可以支持群体风险评价，但普通统计界不自动构成新算法。

当前结果：**retain 0，新机制尚无合格候选。** 不派生第四个相近启发式、不重新调已探索队列、不启动新问答。后续若恢复，需实质不同的问题、可观测动作或明确测量资源范围，重新冻结强对照、来源隔离、成本和样本量协议。
