# 路线2：不依赖 gold 必需区间的长视频选帧鲁棒性研究预注册（科学负责人草案）

**创建：2026-10-09；状态：SCIENTIFIC DRAFT / NO GPU / NO DATA RELEASE.** 本文件更新研究方向，不是已执行实验、算法创新保留或数据许可证。用户已明确从旧路线1**改选路线2**。历史 [TRACE咨询稿](./outreach/trace-ves-bench-inquiry-draft.md) 继续保留为未发送草案，**不再是待执行任务，禁止擅自发出**。

## 1. 科学问题及适用性

研究对象：**在固定12个唯一源视频帧预算下，问题感知的帧选择是否具有可重复的、在来源与成本可比条件下的性能或鲁棒性差异？变化中有多少可能只是选帧路径对问题表述的敏感性，而非模型利用视频证据的因果机制？**

不再假设、读取或声称“已经覆盖 gold 必需证据区间”。新的实验**仍然需要**合法的视频/QA使用权、与选帧隔离的正确答案评分器、实际PTS/媒体版本、来源组排除、处理器与token成本核对。**“无 gold”只指不需要 gold *证据区间* 构造选帧，不等于不需要合法的QA答案用于事后评分。**

### 主要可证伪假设 H-P（现象层）

- 总体：在事先确定的合法长视频QA来源组上，冻结主模型/处理器及可用帧池、每臂12个不同真实源帧、解码和提示协议。
- `S_q`：在**不访问正确答案或答案表现**前提下，按指定问题—候选帧相似度选帧；`S_t`：问题无关、时间分层/时间bin匹配的固定采样，二者使用**同一合法候选帧池**。
- 预定义主要估计量：`Δ_accuracy = E_group[Y(S_q,q)-Y(S_t,q)]`，`Y∈{0,1}`，失败/空答按原定规则计0；按全部预注册来源及预定排除/构造失败报告完整分母。**H0：Δ=0，双侧H1：Δ≠0**，不先假设有提升。
- **否决标准**：差异在预设样本/外部来源复核中不稳健、或仅由明显token/时钟/源身份/构造不公平驱动，不能提升成“问题相关采样有效/失效的机制”；负结果照实保留。置信区间跨0不是等效性证明。

### 附加可证伪假设 H-S（选帧路径脆弱性，必须先具备有效改写对）

- 在**意义等价且事前确认**的一对问题措辞 `q,q'` 下，保持**最终回答提示始终为原q**，仅令问题感知选帧器分别取 `S_q` / `S_q'`；该成对正确率和回答翻转率差异，衡量*selection-path sensitivity*，不能声称语义因果。
- 另一正交对照：固定相同的选中帧，只改变回答提示 `q→q'`（prompt-only），区分prompt敏感和selection敏感。若数据没有合法、事前审核的等价问题对，则该副研究标为**NOT FEASIBLE**，不由Codex自动生成、使用评分结果挑选或冒称等价；不新增人工标注。
- `H0_S`：选帧路径不同输入造成的配对回答/正确性变化在预定义目标总体中为0；`H1_S`：不为0。仅在有效样本和等价性审核成立时才能测试，不能把“不同措辞使帧不同”这种机械事实写成模型鲁棒性突破。

### 禁止的机制推论

哪怕观察到`Δ`或选帧路径差异，也**不能**自动证明模型不看图、注意力被分散、检索相似度导致错误、原视频包含/不包含充分证据；还不能自称产生新算法。帧时间位置、画面可辨性、内容差异、内部patch/token数、问题措辞本身、场景复杂度和训练集污染均是强反解释。

## 2. 主要干预与强对照

| 组 | 选帧规则（12唯一源帧、冻结候选宇宙） | 核心作用 |
|---|---|---|
| `S_t` | 问题无关、时间分层均匀/确定性规则 | **主对照**，不读取答案 |
| `S_q` | 固定旧版SigLIP问题—帧相似度，按预注册候选与打破并列规则采12帧 | **主要处理**；现有技术，不是新算法 |
| `S_d` | 问题无关的多样性/语义边界对照，具体算法先做文献去重再冻结 | 强基线；不因性能差而事后调参 |
| `S_shuf` | 用预定来源独立、任务格式可比但不对应本视频的替代问题进行相似度选帧，**回答仍问原题q** | 负对照，揭示选帧规则与词面/分布混杂；不是语义因果隔离 |
| `S_fixed` | 选帧固定、只改变最终回答提示（仅在H-S合法同义改写可用时） | prompt-only对照，**可选** |

所有对照先冻结算法、随机种子、候选帧宇宙、同一个视频版SHA/PTS、唯一帧key、问答协议与允许的每题臂集合；不存在相关元数据时不要产生真假“公平PASS”。禁止用题目的正确答案/历史评分来挑帧、挑扰动、调整阈值或抛弃失败题。

**强制比较和限制**：

- 严格12 **唯一源帧**，源帧复用、视频内部patch、融合帧均不能冒充12个源帧。若不同选择使实际视觉token、分辨率或预处理不同，要量化或视主机制解释为不成立，不用空跑“补平”成本。
- 真实PTS/timebase与clip偏移绑定具体SHA；用index/FPS仅可做探索诊断，不得冒充真实时间匹配。控制粗bin后还须核实bin内时间跨度；同帧数量和大bin直方图一致不足以排除时间混杂。
- 问题相关与时间分层的源帧内容不可逐帧完全相同，因此主要效应是**预定义选帧策略总体效应**，不是问题相似度这一特征的纯净因果效应。
- `S_shuf` 只处理可用的非答案问题文本；不得从保护/封存集合取题或向模型泄漏隐藏答案。
- 旧历史探索/校准/审计/封存组与新确认组独立；`789=339+450`描述历史排除域摘要覆盖，不代表789独立来源。来源关系UNKNOWN则不能认证新来源独立性。
- 预先报告建样成功率/失败原因；构造失败不可按结果事后替换，硬性门失败则不得开始本阶段模型实验。

## 3. 统计与成本（待数据门通过后才冻结数字）

主要 `Δ_accuracy` 和完整配对 `2×2` 纠错/误伤表；次要回答翻转率、时间bin偏差、来源组分层、处理器实际视觉token/实际wall及IO/采帧成本。不得把同视频多个问题视为独立组。按保守来源组聚类置信区间；对于适用的配对设计可预注册精确置换/符号检验。主要比较`S_q-S_t`**只有一个**，其余均辅助/敏感性分析；无事前控制不对一堆子群选择显著者。

样本量和GPU调用预算**当前未批准**。不能套用旧40–60或240次预算；须用新的来源规模、配对不一致率、最小实际效应及预算先算功效，再由用户单独授权。记录每个预定问题/臂planned→started→terminal，started不自动重播；独立评分器只在执行完成后读取gold答案，失败/无答案计0，纠错/误伤同报，GPU串行与锁真实持有确认后才可谈实验。

## 4. 新数据和可执行门槛

**NG0科学差异**：需对 Q-Frame、VidF4、M-LLM Frame Selection、DIG、VideoITG、VideoStir、2024 VideoQA行为研究等**阅读全文/方法**而非仅摘要，证明要测的*独特对照*是否尚未直接覆盖；若已有直接同样试验，则降为**复现/负结果研究**，**不将它包装成新方法/《计算机学报》创新**。

**NG1合法数据**：必须明确视频与QA问答/评分使用许可，授权非商业评测与聚合结果披露。数据只需要合法QA评分标签和无答案选择投影，**不需要gold证据区间**；独立来源/帧时间与媒体版本仍必需。标签评分器隔离。

**NG2状态与方法**：本地可读的媒体/时钟/来源排除域与原实验进程/锁/不可重播账本确认，12唯一帧、多个强基线和token成本具可实现途径。若只剩历史20个探索源，不能声称有可验证独立确认样本。

**NG3科学预注册**：先冻结单个主要效应、样本量/最小效果、先导与独立确认来源划分、测试方法、退出门槛、实际GPU/时长开销上限；不能因toy或已有历史结果跳过。

当前 NG0、NG1、NG2、NG3 **全部未通过或尚未验证**。G1旧gold区间数据门已成为**路线1历史门槛**，不再强迫路线2寻找必要区间；但新路线有不同的合法数据NG1门，不能以“放弃gold”逃避媒体许可。
