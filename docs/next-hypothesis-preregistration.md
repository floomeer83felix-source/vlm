前提：[历史负结果审计](./research-failure-audit.md)；[2026文献差异矩阵](./novelty-gap-matrix.md)。  
**这是一份计划，不包含任何新的模型结果。用户已恢复研究授权，但本轮没有可访问的本地3090进程、账本和视频，因此未触发GPU调用。**

## 1. 唯一主要问题及可证伪假设

**研究问题**：在相同问题、冻结模型、12个唯一源视频帧、相同已标注“必需证据区间”的源帧均出现的前提下，将其余槽位由均匀背景帧改为**与问题较相似、但不位于已标注必需区间内**的帧，是否会降低最终问答准确率？

- H0（主要统计零假设）：干预（D2）与中性背景（D1）在预定义总体中的配对期望正确率差等于0。
- H1（方向性研究假设）：D2 相对于 D1 具有**负**的配对期望准确率差；纠错/误伤两种翻转均必须报告，不用仅统计误伤来支持方向。
- 非推论：即使H1成立，也不等于证明注意力被分散、视觉证据已被充分感知、或提出了新算法；“必需区间外”只是特定注释协议下的代理定义，可能含未标注的有用信息。

**主要估计量**：D2 与 D1 对相同问题的全计划正确率差 (mean(correct_D2 - correct_D1))；报告 R=原错→新对、H=原对→新错和净效应 R-H（以全部有效计划配对为分母，执行失败/空回答计0并保留在分母）。

## 2. 模型、硬件与执行约束

- 主模型：原冻结 Qwen3-VL-4B-Instruct，保持原版本/处理器/权重；检索器 SigLIP 原版本，只用于干预构造的相似度排序，不输入标签。
- 硬件：本地 RTX 3090 + 64 GB；使用现有 conda pytorch 环境，不新增环境、不升级/更换 Python/Torch/CUDA；GPU 串行。
- 无付费 API、云 GPU、新增人工标注；不可借模型进行私有评分标签泄漏式“标注”。
- 先核对真正运行的进程、GPU锁和既有调用账本；未确认可恢复性前没有新QA调用。
- 保持每题**12个唯一视频源帧**、时间戳、图像分辨率/patch策略、选项表达、生成参数、输出解析器及上限固定；实际视觉token/时延如有差异必须记账。
- 不重跑历史300题及已关闭候选；旧校准/审计/封存样本不能因新策略失败而被挪回探索。

## 3. 参考证据资源进入条件（先做、只读、零GPU）

候选顺序（不是已选定数据集）：VES-Bench（已标注联合必需时间区间）→ HERBench 的固定版本关键帧/标注子集 → CaST-Bench 时空链。先依据来源页面元数据确定许可和精确文件大小，不下载整套媒体。

所选数据必须同时满足：

1. 每题有公开、可机械解析的必要证据区间/关键帧；能确认注释与同版本视频流的时钟和帧桥接；若只有“参考帧”没有区间，另预注册其可操作定义，不擅自当严格必要区间。
2. 不访问测试评分标签来选择帧；选择问题和证据集合的程序不可利用题目对模型的历史答题表现。
3. 每个候选视频有稳定内容SHA、事件/场景/来源组 ID；排除历史探索/校准/审计/保留的已知组件，未知源重合明确记为未知。
4. 12帧预算内可以**至少覆盖三个非重叠参考证据时段**（若数据集任务要求更多，按其公开定义），并且余下槽位可构造两个不重合的参照来源池。
5. 视频、帧、字幕和标注的版权/研究许可证允许此本地用途。可用源不足时本计划 HOLD，不用劣质替身、无界下载或改动采样门槛。

版本漂移防线：HERBench 论文和仓库报告过不同总题数，HF 新增 lite_v2；固定 repo commit/HF revision/文件SHA/split/媒体manifest后才开始构造干预。

## 4. 问题与源抽样（在读取任何本阶段模型分数前固定）

- 操作性来源组是抽样主单位；同一事件跨剪辑、同视频题目、同源上传的近重复应被合并，无法证明独立时使用保守的大组。
- 探索先导目标：约40–60个可用且尽可能互异的来源组，每组选**一个**问题；达到数量取决于元数据门，不能先定为40题后悄悄补样。
- 从满足证据条件、长度条件、许可条件的全体中，按**SHA散列的预设确定性次序**取首批；相似度和后验正确率均不能决定能否入选。
- 首先生成源身份清单，固定排除集和每题证据区间，然后**封存候选清单**。同事件源跨不同集合不得同时进入探索与确认。
- 先导只是估计噪声、干预可实施性与可复查现象；之后的样本量按最小有实际意义的配对效应、预期不一致率、来源组聚类及错误率预算确定。40–60组**绝不宣称具有检出小效应的统计功效**。

## 5. 四臂干预：先明确定义，后执行

所有臂最多12个唯一源帧；无特殊记录不得增加视觉token预算。若参考区间帧数量 k >= 12 无法容纳两个背景池，则该题**预先标记不适用**，而不是对某臂减少帧数。

| 臂 | 12帧构成 | 用途 | 主要/辅助 |
|---|---|---|---|
| D0 | 旧基线固定策略选12帧（优先现有IMAGE12或与之等价的处理器接口） | 真实可部署强对照；不读参考证据 | 辅助 |
| D1 | k个参考区间锚帧 + (12-k) 个区间外均匀背景帧 | 同证据覆盖的中性参考 | **主对照** |
| D2 | 与D1完全相同的 k 个锚帧 + (12-k) 个区间外、SigLIP问题相似度排序最高的合规帧 | 研究问题相似度较高的区间外信息影响 | **主实验** |
| D3 | D1中一个预定必需区间锚帧替换成区间外背景帧，仍12帧 | 对参照标注的重要性进行操作性检查 | 诊断；不能据此证明语义充分性 |

**锚帧预定义**：每个非重叠参考区间选择该区间中心时间最近的一帧，若有公开可信参考关键帧优先使用其预定义帧；相同时戳依固定哈希打破。解码实际帧PTS、目标时间、容差和落点必须记录；超出区间的帧为构建失败，不可无记录近似通过。

**区间外池**：与全部参考区间的时间距离须满足固定保护带（保护带宽度由元数据时间精度预定，在任何QA前冻结）；从非锚帧、非重复源帧、合法时间范围内选。D1用时间均匀填充；D2用固定SigLIP query-frame cosine分数降序、SHA+PTS确定性破同分；不能按答案选项文本或评分标签筛选。若D1/D2不足相同个数槽位，题目提前排除且报告原因；不补其他题以掩盖排除。

**D3 删除规则**：按参考区间开始时间排序，删除第一个锚帧，替换为固定散列选出的合规区间外帧；如果同一参考区间本有其他覆盖帧，则必须重新验证删除后该区间是否真的不再被覆盖。D3只作标注操作性检验。

**一致性检查**：
- D1/D2的锚帧文件 SHA/PTS 相同，12帧互异、时戳跟踪完备。
- 统一按真实PTS递增打包，不通过乱序引入新混杂；其它视觉/文本处理相同。
- 若D2选择了与D1相同的区间外帧，记为同构干预并在主要全计划分母中保留；另报告非同构子集但不作为主要结论。
- 如果参考区间“必要性”的公开证明不成立，不能把 D3 标签解释为必需证据被移除；数据门失败时不执行。

## 6. 随机化、评分隔离与技术账本

- 在运行前冻结题目全集、所有输入帧/哈希/PTS/臂配置、版本、运行成本上限和输出协议，保存不可变 manifest 及 SHA256。
- 单题四臂在硬件/锁保护下顺序执行，臂执行顺序由问题 SHA 派生的固定平衡次序，避免系统性的热启动偏置；可用同一模型权重驻留，但记清每臂冷/热模型加载成本。
- 输入构造器只见问题/选项、视频、公开的离线参考证据（仅用于 D1-D3）；回答模型和在线策略不得见参考标注或正确选项。
- 评分器独立读标准答案；评分结果不会被采帧/策略/中止规则读取；无答案、超时或不合法解析当 correct=0，记录独立错误码，原正确→新错误计误伤。
- 每个问题×臂唯一调用ID，write-ahead持久状态：planned → started → terminal；恢复时 started 不得自动重做前向，先审计事实。
- 每臂记录解码、SigLIP索引、问题编码、处理器、模型文件IO、GPU前向、生成、独立评分、重试/恢复/日志开销；共享准备/启动费用单列，既不抹去也不伪装为部署折扣。
- 首题在真实处理器检查12个唯一源帧和时戳、前四次问答核验后方可推进；遇到锁不明、数据桥接错误、任何跨界标签泄漏即停止并保存终态报告，不“修好后选择性重试”。

## 7. 统计方案（先导）

定义每题分数Y∈{0,1}，不可用、无效或失败Y=0。主要对比 Δ=mean(Y_D2-Y_D1)；纠错R=P(D1错误且D2正确)，误伤H=P(D1正确且D2错误)，满足 Δ=R-H。结果按**完整预定分母**计算。

- 报告全部题数、实际构建失败数、源组数、互异输入百分比、全部四臂配对2×2交叉表。
- 不假设每题独立；以保守操作性来源组为重采样单位，输出带固定seed和完整复现脚本的描述性95% cluster-bootstrap区间，并在可适用时报告精确配对符号/置换检验。
- 预先分层报告：证据区间数、持续时长、任务类别、来源、相似度间隔；这些均**探索性**，不得事后挑最显著的子群作为已确认核心主张。
- 严禁将跨0区间解释为等效，也不得将样本内非零均值解释为通过科学门槛。
- 若数据集的选项/文本先验足以作答，应以事先固定的 **文本/空视觉附加诊断** 衡量可能捷径；新增诊断是额外模型调用，必须独立预算、记录，不偷偷并入四臂。
- 不把单视频多问题/多随机种子当独立来源，也不将用户交互中逐轮挑选的最佳方法与封存确认集混用。
